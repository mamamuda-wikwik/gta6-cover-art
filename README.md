Vice City Cover Studio — turn your photo and a caption into GTA-style multi-panel cover art, in the browser, offline. Fill a hero panel and smaller panels with one photo or several, crop and position each panel by dragging, pick a layout (Poster, Duo, Trio) and a neon grade (Sunset, Neon, Gold), letter the caption in condensed display type, and export the cover as a PNG in the common post sizes: 1080 x 1080, 1080 x 1350 and 1920 x 1080 — one size or all three in one step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The app is plain static files under `app/` — no build step, no network requests. Photos are read on your own machine and never uploaded. The two sample photos under `app/samples/` were made for make.fun with an image model and are free to use. The display type is Anton (SIL Open Font License 1.1, vendored under `app/fonts/`).
